To deploy to the live website:

Run the command:

  ng deploy --cname=kintscher.dev

This will deploy to the gh-pages branch by default. **WARNING: This will overwrite any existing files on the branch.**

---

To deploy locally:

References:
https://angular.io/guide/deployment

Run the following commands:

  1. ng build --output-path docs
  2. git commit -m "[message]"
  3. git push

  After running #1, copy the content of the docs/index.html and paste it into docs/404.html

  Copy the CNAME file back into the "docs" directory.
